# 100% acceptance bar

100% means ready to put in front of Publicis and a paying brand.
Not “the build passed.”

## Product gates

- [ ] Consumer: discover → pin → check-in → hold → wallet → impact
- [ ] Brand: studio → pin → reward → fund (performance slice) → publish → LIVE moves
- [ ] Creator: copy `?ref=` → attributed unlock → pending → available
- [ ] Admin: withdrawals requested / paid without editing ledgers by hand

## Real world

- [ ] GPS check-in works on iPhone Safari and Android Chrome
- [ ] Outside radius rejects
- [ ] Accuracy > 250m rejects
- [ ] 10-minute repeat check-in rejects

## Money

- [ ] Brand deposit (Paystack live or labelled sandbox)
- [ ] Campaign budget reserved
- [ ] Visit CPE ledger row on verified pin check-in
- [ ] Unlock / XP do not debit brand
- [ ] Creator payout to bank (Paystack Transfer or written ops runbook)

## Data

- [ ] LIVE: people, visits, unlocks, redemptions
- [ ] Cost per verified visit
- [ ] Funnel conversion between stages
- [ ] Creator contribution visible

## Security

- [ ] Tenant isolation tested
- [ ] Consumer cannot self-award Impact
- [ ] Client cannot write money tables
- [ ] Financial RPCs not granted to anon

## Experience

- [ ] Campaign understood in five seconds
- [ ] One primary action per screen
- [ ] Empty / error / permission-denied states
- [ ] `/demo` path run on production data the day of the meeting

## Commercial

- [ ] `/for-agencies` states the category
- [ ] Terms + privacy current
- [ ] One flagship campaign, not ten mediocre ones

If any box is unchecked, do not say 100%.
